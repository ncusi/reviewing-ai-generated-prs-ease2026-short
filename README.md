# MSR Mining Challenge 2026
This repository contains experimental materials for research project submmited to MSR Mining Challenge. Research focuses on analysis of pull requests reviews created by human developers and by AI-based tools

## Abstract
The study analyzes and compares pull request reviews authored by human developers and those generated by AI systems.
Using a given AiDev dataset and additional data collected via GitHub API, we investigate differences in review characteristics, patterns and content. 
All experiments and analyses are implemented as Jupyter Notebooks to support transparency and reproducibility.

## Repository Structure
* `Data/` # Dataset 
* `README.md` 
* `RQ1.ipynb` # Analysis of AI-generated pull request reviews
* `RQ2.ipynb` # Analysis of human-generated pull request reviews
* `Table.ipynb` # Prepared tables
* `Tests.ipynb` # Statistical tests

## Reseach Questions
* **RQ1:** What does the human review process look like for AI-generated pull requests?
* **RQ2:** How does human review of AI-generated PRs compare to review of human-authored PRs within the same repositories? 

## Notebooks Description
### `RQ1.ipynb`
This notebook contains:
* loading and preprocessing AI-generated PR review data for RQ1

### `RQ2.ipynb`
This notebook contains:
* loading and preprocessing human-generated PR review data for RQ2

## Reproducibility
All experiments can be reproduced by executing notebooks cells in sequential order.

## Requirements
The project was developed using:
* Python 3.13.3
* Jupyter Notebook

Main dependencies include:
* numpy
* pandas
* scipy

## Running the Experiments
1) Clone the repository:
```bash 
git clone https://github.com/ncusi/msr-mining-challenge-2026.git
```
2) Install dependencies:
```bash
pip install numpy pandas scipy
```
3) Launch Jupyter Notebook:
```bash
jupyter notebook
```
4) Open and execute notebooks
* `RQ1.ipynb`
* `RQ2.ipynb`

## Data Availability
Parquet files from AiDev dataset used in this study are included in `Data/` directory. Full dataset can be obtain by executing `download_aidev.sh` script included in `Data/` directory. Other external data can be obtain by executing specific Jupyter Notebooks in `Data/Changed Lines AI`, `Data/Changed Lines Human`, `Data/Comments Human`, `Data/Inline Comments Human` and `Data/Reviews Human` directories.

All data required to reproduce experiments is included in this repository.
